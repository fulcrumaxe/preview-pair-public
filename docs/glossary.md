# Glossary

**Work item** - A unit of planned work, such as a GitHub issue, that the platform tracks through its lifecycle from specification to a merged pull request.

**Planned pull request** - A pull request whose scope was decided in advance as part of a Spec, often one of several children that together implement a larger work item.

**Paired repository** - A repository that is linked to another so that changes made in one can be mirrored, tested, or reviewed in the context of the other.

**Spending limit** - A cap on the resources (such as time, API usage, or cost) that an automated process may consume while completing a work item.
